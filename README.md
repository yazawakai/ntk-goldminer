# 新三国黄金矿工 New Three Kingdom Gold Miner（Python + tkinter）

一个**零第三方依赖**的黄金矿工：钩子旋转 → 发射 → 抓金块 / 石头 → 计分 → 倒计时 →
3 个关卡 + 随机无尽关卡 → 随机物品 → 商店买道具（炸弹 / 酒）→ 计分板 → 关卡提示 → 抓取动画与音效，
贴图和音效都可以直接换成你自己的文件。

```
python main.py          # 运行（会打印一行资源自检）
run.bat                 # 双击启动（用 pythonw，无控制台窗口）
python tools/make_default_assets.py --force   # 重新生成默认贴图 / 音效
python tools/smoke_test.py                    # 自动化冒烟测试（无需人工操作）
python tools/screenshot_demo.py               # 自动演示并把各界面截图到 shots/
```

环境：**Python 3.10+，只需标准库**（tkinter 随 Python 安装；Windows 用系统自带
MCI 多路播音效，新音效不打断旧音效；其他平台 / 无音频设备自动静音降级）。
不需要 pygame / Pillow。

## 1. 玩法与操作

| 按键 | 作用 |
| --- | --- |
| `空格` / `回车` | 发射钩子（菜单里是开始游戏，商店里是进入下一关） |
| `1` | **炸弹**：矿场里 = 使用（炸掉钩子上已抓住的东西，空钩极速返回）；商店里 = 购买 |
| `2` | **沛国佳酿**：矿场里 = 使用（12 秒内收绳速度 ×1.9）；商店里 = 购买 |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |
| `R` | 结算界面重新开始 |
| `Esc` | 退出 |

规则：
* 钩爪的起点在**矿工脚下**（`config.PIVOT = (WIDTH//2, GROUND_Y + 18)`，想再高/再低改这个数），
  在下方左右摆动，`空格` 发射；抓到东西后自动收线。
* **越重收线越慢**：`收绳速度 = 300 / (1 + 重量)`。
* 每关有**累计目标分数**和**倒计时**。**达到目标分不会立刻结束关卡**（经典规则），结算条件只有两个：
  1. **时间耗尽**：累计分数 ≥ 目标 → 过关；没达标 → 游戏结束（可输入名字存档）；
  2. **提前把矿场挖空**：立刻过关，剩余时间按 **10 分/秒** 折算成清场奖励。
* 过关后先进入**商店**（用分数买道具），按 `空格` 正式开始下一关；
  第 4 关开始是随机生成的无尽矿脉，**没有终点**，直到你某关没达标为止。
* 达标后可以继续挖分：HUD 进度条变绿并显示「✔ 目标已达成 · 挖空矿场可提前过关（剩 N 件）」，
  多挖的分全部计入累计总分。

物品与分值：

| 物品 | 分数 | 重量 | 说明 |
| --- | --- | --- | --- |
| 小金块 / 中金块 / 大金块 / 巨型金块 | 50 / 100 / 250 / 500 | 1.0 / 1.5 / 2.2 / 3.0 | 主力收入 |
| 小石头 / 大石头 | 11 / 20 | 2.0 / 3.4 | 拖慢节奏，炸弹可以清掉半径内石头 |
| 钻石 | 600 | 0.6 | 最值钱、最轻 |
| 钱袋 | 120–480 随机 | 1.2 | 随机分数 |
| 帅案 | 166 | 1.2 | 张飞掀帅案在折棒吐槽新三国第166期 |
| 笑面虎 | 300 | 2.0 |  |
| 乌角鲨 | 450 | 2.5 |  |
| 龙 | 868 | 4.0 | pjsk黄谱龙音符数量 |
| 仁之剑 | 120 | 1.0 | 《泰拉瑞亚》的永夜刃 |
| 义之剑 | 120 | 1.0 | 《泰拉瑞亚》的断钢剑 |
| 四轮车 | 100 | 1.5 | 《泰拉瑞亚》的高尔夫球车 |

> 道具只在关卡之间的**商店**出售。

关卡结构：**3 个手工设计的简单关卡 + 之后随机生成的无尽矿脉**（第 4 关起每关都不一样）。

| 关卡 | 时间 | 累计目标 | 摆动速度 | 发射速度 | 特点 |
| --- | --- | --- | --- | --- | --- |
| 第 1 关  | 60s | 650 | 95°/s | 620 px/s | 一把叫仁之剑，一把叫义之剑 |
| 第 2 关  | 55s | 1400 | 110°/s | 680 px/s | 一对笑面虎，两头乌角鲨 |
| 第 3 关  | 52s | 2250 | 125°/s | 740 px/s | 龙，可是帝王之征啊 |
| 第 4 关起（随机） | 50s↓ | +700±250/关 | +4°/关 | +16 px/s 每关 | 地名、物品表、道具数量全随机，天意侵蚀程度不断加深 |

随机关卡规则（`gm/config.py` 里可调）：

```
目标分   = 上一关 + 700 ± 250（只增不减，保证越来越难）
时间     = 52 - 2×第几个随机关，下限 34 秒（只减不增）
摆动速度 = 125 + 4×i °/s，上限 180     发射速度 = 740 + 16×i px/s，上限 980
物品表   金块/石头/钻石数量随难度档位递减，新三特有物品递增
地名/提示 从 RANDOM_PLACES / RANDOM_HINTS 里随机取
```

* 随机关卡**每局重新洗牌**（`start_game()` 调用 `C.reset_random_levels()`），同一局内同一关的
  配置会被缓存，保证钩子速度不会逐帧抖动。
* 无尽模式下只有“时间到没达标”才会结束，所以分数会一直累积，直到你失手为止。
* 通过第 3 关时会记录“已通关 3 个简单关卡”，排行榜里会显示 `通关` 标记。

## 2. 商店（经典《黄金矿工》界面）

每关结束（过关过场播完）自动进入商店：木板小店 + 柜台 + 白发店长 + 货架上的商品和价格牌，
**鼠标操作为主、键盘也能用**，买完点「进入第 N 关 →」出发。

```
┌──────────────────────── 矿 工 商 店 ────────────────────────┐
│   [气泡：店长说话]       ┌─[1] 炸弹─┐  ┌─[2]沛国佳酿─┐      │
│      (＾▽＾)  店长       │   💣     │  │    🧪       │      │
│     /|   |\              │  215 分  │  │  305 分     │      │
│     柜台 ══════════      │ 已有 x1  │  │ 已有 x0     │      │
├──────────────────────────┴──────────┴──┴─────────────┴──────┤
│ 💰 金币（分数） │ 下一关：第 4 关 目标 2927 分│ 进入第 4 关 →│
│      2250       │ 已达标 ✔ 可以放心花钱      │             │
└─────────────────────────────────────────────────────────────┘
```

| 操作 | 效果 |
| --- | --- |
| 鼠标移到商品卡 | 卡片金色描边高亮 |
| **点击商品卡**（或按 `1` / `2`） | 买下该道具，直接扣分数 |
| **点击店长** | 他会随口说一句挖矿心得 |
| **点击「进入第 N 关 →」**（或按 `空格` / `回车`） | 离开商店，进入下一关 |

**店长立绘与语音**（文件名即资源名，映射写在 `config.SHOP_KEEPER` / `config.SHOP_VOICE` 里）：

| 时机 | 立绘 `assets/images/<名字>.png` | 语音 `assets/sounds/<名字>.wav` |
| --- | --- | --- |
| 平时（逛店 / 买到东西闪一下） | `gongxidiekeyichengdile` | — |
| 一分钱没买就离开 | `jingranbuxu` | `jingranbuxu` |
| 买过东西后离开 | 沿用平时那张 | `gongxidiekeyichengdile` |

* 立绘会**先放大、再按相框居中裁切**（Tk 只支持整数倍缩放，内部用 `zoom`+`subsample`
  拼出 1.5 这类倍率，裁切用 `image copy -from/-to`），所以不会拉变形，也不会留黑边。
  尺寸与倍率都在 `config.py` 里：

  ```python
  SHOP_KEEPER_FRAME = (30, 92, 556, 458)  # 相框外框 x0,y0,x1,y1（960x640 逻辑坐标）
  SHOP_KEEPER_PAD = 12                    # 相框边厚 → 内画面 = 外框内缩这么多
  SHOP_CAPTION_H = 40                     # 相框内底部台词条高度
  SHOP_KEEPER_ZOOM = 1.5                  # 立绘本身的放大倍率（1.0 填满相框 / 2.0 怼脸特写）
  ```

  默认内画面 502×302 逻辑像素，在 200% DPI 屏上按 **1004×604 真实像素**去适配
  （高 DPI 下不会糊成半个相框），所以两张 490×280 / 400×300 的立绘会被放大到填满相框。
  台词显示在相框内的台词条里（"店长：…"）。
* 两张立绘都没有时，会自动退回代码绘制的矢量老店长（`neutral / happy / sad` 三种表情）。
* 换图/换语音只要替换同名文件，或者改 `config.SHOP_KEEPER` / `config.SHOP_VOICE` 里的名字。
* 想让店长把语音说完再进关，把 `SHOP_REACTION_TIME` 调大（默认 1.2 秒）。
* 台词写在 `config.SHOP_TALK`，写成字符串、单元组或多句元组都行
  （`("竟然不许！")` 这种少写逗号的字符串、甚至 `("竟","然","不","许")` 逐字写开，
  `shop_talk()` 都会还原成完整一句）。

商品与规则：

| 商品 | 热键 | 售价公式（关数从 1 起） | 效果 |
| --- | --- | --- | --- |
| 炸弹 | `1` | `min(900, 180 + 35 × (关数-1))` | 炸掉钩子上已抓住的东西，空钩 6 倍速返回 |
| 沛国佳酿 | `2` | `min(1100, 260 + 45 × (关数-1))` | 12 秒内收绳速度 ×1.9 |

* **货币就是分数**：购买直接从累计分数里扣（和经典黄金矿工一样）；分数不够会提示 + 播放“无效”音效。
* 底部面板显示 `金币（分数） / 下一关目标`，并提示「已达标 ✔ 可以放心花钱」或
  「还差 N 分才达标，留点本钱！」——目标分是累计的，花太多就得靠下一关多挖回来。
* 商店里摆好的那份矿场会**原样**带到下一关（`pending_items`），不会重新随机一遍。
* **买来的道具跨关保留**，不会每关重置；开局自带 0 个（改 `config.START_PROPS` 可送）。
* 想让矿场里重新随机刷出道具：把 `gm/config.py` 的 `PROPS_IN_FIELD = False` 改成 `True`
  （关卡表里的 `bomb_pickup / potion_pickup` 数量会照常生效）。
* 想加新商品：在 `config.SHOP` 加价格、加进 `SHOP_ORDER`，再在 `game.buy()` 里加效果即可，
  商店界面和点击区域都是按 `SHOP_ORDER` 自动排布的。
* 想换店长形象：把 `shop_neutral.png` / `shop_happy.png` / `shop_sad.png`
  （建议 220×240，人物脚底对齐底边）放进 `assets/images/` 就会自动覆盖矢量店长。
* 台词全部在 `config.SHOP_TALK` 里，按 `greet / bought / poor / bye_spent / bye_free / idle` 分类，改文案不用碰代码。

## 4. 换成你自己的贴图和音效

**贴图**：把 PNG 丢进 `assets/images/`，文件名必须与下表一致；找不到对应文件时游戏
会自动退回代码绘制的矢量图形（所以删掉整个目录也能跑）。

| 文件名 | 逻辑尺寸(px) | 建议原图尺寸 | 内容 |
| --- | --- | --- | --- |
| `background.png` | 960×640 | 960×640 | 整张背景（天空 + 泥土） |
| `miner.png` | 84×84 | 168×168 | 矿工，右手应位于图片高度 **30%** 处（绳子起点） |
| `gold_small/medium/large/huge.png` | 30 / 40 / 54 / 68 | 60 / 80 / 108 / 136 | 金块 |
| `rock_small/large.png` | 36 / 56 | 72 / 112 | 石头 |
| `diamond.png` | 28 | 56 | 钻石 |
| `money_bag.png` / `mystery_bag.png` | 38 | 76 | 钱袋 / 神秘袋 |
| `bomb_pickup.png` / `potion_pickup.png` | 34 | 68 | 炸弹 / 沛国佳酿（矿场与商店图标共用） |
| `gongxidiekeyichengdile.png` / `jingranbuxu.png` | 相框内画面 502×302（按 `SHOP_KEEPER_ZOOM` 放大后居中裁切） | 任意（保持宽高比，整数倍缩放） | 商店店长立绘：平时 / 没买东西（名字由 `config.SHOP_KEEPER` 指定） |
| `shop_neutral.png` / `shop_happy.png` / `shop_sad.png` | 220×240 | 440×480 | 可选：商店店长的三种表情（缺省用代码绘制的矢量店长） |

**加自己的物品**（不用改代码）：在 `gm/config.py` 的 `ITEMS` 里加一条，例如

```python
"shuaian": dict(label="帅案", score=166, weight=0.5, r=18),
```

再把 `shuaian.png`（尺寸 ≈ `2×r+4`）丢进 `assets/images/`，最后把它写进关卡表的 `spawn`
（`spawn=dict(..., shuaian=1)`）或随机关卡生成器 `make_random_level()` 里。
**忘了放 PNG 也不会变成隐形物**：`_draw_item_vector()` 有一个通用兜底，
会按物品名算出一个稳定的颜色画成宝石并写上名字首字。

* 用 **RGBA PNG**（带透明通道），游戏按物品半径自动缩放到合适大小。
* 在 200% 缩放的屏幕上画布会放大 2 倍，图片会被 `zoom(2)` 精确放大，所以在
  96 DPI 下准备 2 倍图（“建议原图尺寸”）能得到最清晰的效果。
* 钩爪和绳子是**按角度实时旋转绘制**的（Tk 图片不支持旋转），所以没有 `hook.png`；
  想改颜色改 `gm/config.py` 里的 `COLORS["hook"] / ["rope"]`。

**音效**：把 WAV 丢进 `assets/sounds/`，文件名必须与下表一致（缺文件自动静音）。

| 文件名 | 触发时机 |
| --- | --- |
| `hook_shoot.wav` | 发射钩子 |
| `hook_hit.wav` | 钩子抓到东西 |
| `collect.wav` | 收获计分 / 保存成绩 |
| `nya.wav` | 炸弹爆破 |
| `dangfuyidabai.wav` | 使用沛国佳酿 |
| `level_up.wav` | 过关 |
| `guanyu_song.wav` | 游戏结束 |
| `tick.wav` | 最后 10 秒每秒滴答 |
| `deny.wav` | 道具用不了等无效操作 |

* 用 `22050Hz / 16bit / 单声道 WAV` 最保险（44.1kHz 立体声也照样放，MCI 都吃）。
* 想彻底关掉声音：游戏里按 `M`（会立刻停掉正在响的声音），或把 `assets/sounds/` 清空。
* **多个音效可以同时播放**：新音效不会打断正在响的旧音效，详见下一节。

想批量调整难度，只改 `gm/config.py`：物品分值/重量、关卡时间与目标、钩子速度、
炸弹半径与倍率、沛国佳酿时长与倍率、商店价格、颜色、字体候选、音频声道数都在里面。

## 5. 音频：为什么新音效不会打断旧音效

`winsound.PlaySound(..., SND_ASYNC)` 是**单通道**的：同一进程里后一段声音一响，
前一段立刻被系统掐掉（例如“抓到钻石”的叮会把“炸弹爆炸”切断）。

所以 `gm/audio.py` 换成了 Windows 自带的 **MCI（`winmm.dll`）多路播放**：
每个 `alias` 都是一个**独立的 waveaudio 设备句柄**，由系统混音器叠加输出，
用一个 **8 声道的声道池**轮转复用：

```
close <alias>  →  open "<wav>" type waveaudio alias <alias>  →  play <alias> from 0
```

* 每次播放都挑一个**当前没在响**的空闲声道 → 已经在播的那几路完全不受影响。
* 万一 8 路全忙（本游戏实测同时最多 3~4 路），就**丢弃这一声新的**，
  **绝不抢断**正在播放的音频 —— 宁可少响一下，也不切断你正在听的声音。
* 全部通过 `ctypes` 调系统 API，**零第三方依赖**；非 Windows / 无音频设备时
  自动降级为 winsound 单通道，再不行就静音。
* 启动时会打印一行自检，可确认当前后端：

```
[音频] MCI 多路混音（8 声道，新音效不会打断旧音效）
```

可调参数（`gm/config.py`）：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `AUDIO_VOICES` | `12` | 声道池大小 = 同时最多几路声音；**加了十几秒的长语音（`level_begin.wav` / `guanyu_song.wav`）就调大一点**，免得长语音占满池子让音效播不出来 |
| `AUDIO_VOLUME` | `1.0` | 0.0~1.0，驱动不支持单独音量时自动忽略 |
| `AUDIO_BACKEND` | `"auto"` | `"mci"` 只用多路；`"winsound"` 强制单通道（做对比用） |

> 声道占用是**按音频时长在 Python 侧记账**的（`_busy`），不去轮询 MCI 状态：
> 实测在“关掉 alias 又立刻复用”的高频场景下，驱动会一直回报 `playing`，
> 那样声道池会被假占用耗尽，最后所有音效都被丢弃。

## 6. 实现要点

* **主循环**：`root.after(16, tick)` ≈ 60 FPS，`dt` 做了 50ms 上限保护（掉帧不会穿模）。
* **钩子状态机**：`swing → shoot → retract → swing`，`Hook` 只存 `theta/length/state`，
  碰撞由 `game` 用「钩爪尖端 vs 物品圆」判定，抓到的物品挂在绳端并带脉冲光环（抓取动画）。
  起点 `PIVOT` 在矿工脚下（绳子从他身下出来，矿工贴图也是双手向下握绳的姿势）。
  因为钩爪只能左右摆 ±`THETA_MAX`，**撒物品时会过滤掉扇形以外的角落**
  （`GoldMinerGame._reachable()`），否则会出现“永远挖不到的东西”，而
  “挖空矿场提前过关”就永远达不成。
* **过关判定**（`game.update()` 里只有两处会结束关卡，达标只做提示）：
  `time_left <= 0` → 达标 `_level_clear(bonus=False)` / 未达标 `game_over()`；
  `not self.items`（矿场被挖空）→ `_level_clear(bonus=True)` 并把剩余时间折算奖励。
  过场文案按 `self.clear_reason`（`"timeup"` / `"clear"`）区分。
* **随机关卡**：`config.level(i)` 对 `i >= len(LEVELS)` 调用 `make_random_level(i)`，
  结果缓存在 `_RANDOM_CACHE` 里（钩子每帧都读配置，必须同一关返回同一个 dict），
  `reset_random_levels()` 在一局开始时清空缓存 → 每局都是新的随机矿脉。
* **高 DPI**：程序声明 DPI 感知；`config.detect_ui_scale()` 按屏幕 DPI 选 1/2/3 倍并把
  画布放大，所有绘制都经过 `Painter`（把 960×640 逻辑坐标 ×倍率），字体用**负数字号
  = 像素高度**，所以 100%/150%/200% 缩放下布局都不会错位，且画面是清晰的整数倍放大。
* **半透明遮罩**：Tk 的 canvas 矩形没有 alpha，所以整屏压暗是用一张 1×1 半透明 PNG
  放大而成（`config.DIM_PNG_B64`）；菜单、暂停、过关、商店、结算五个界面共用它。
* **音频**：`Audio.play()` 走 MCI 声道池（每个 alias 一个独立设备句柄，系统混音叠加），
  池满时丢弃新音效而不抢断旧音效；`Resources.play(name)` 只负责把音效名解析成路径，
  所以游戏逻辑里全是 `self.res.play("collect")` 这种调用，换后端不用改业务代码。
* **商店**：新状态 `shop`，由 `open_shop()` 进入——它把 `level_index` 推进到下一关并
  `_spawn_items()` 预先摆好矿场（`pending_items`），`enter_next_level()` 再把同一份 `items`
  交给 `start_level()`，所以商店里看到的就是正式开打的那一关。
  商店内部还有两个子状态：`browse`（可购买）和 `reaction`（离开时播放店长表情，
  停 `SHOP_REACTION_TIME` 秒再进关卡）；`shop_spent / shop_bought` 记录本次是否消费，
  决定离开时是高兴脸还是不高兴脸。点击区域由 `_shop_layout()` 统一给出，
  渲染和鼠标命中检测共用同一份坐标；鼠标坐标会除以 `self.scale` 换回 960×640 逻辑坐标。
* **性能**：背景只画一次并打上 `bg` 标签，每帧只 `delete("dyn")` 重画动态层，
  场上几十个物品也能稳定 60 FPS。

会以固定步长驱动真实游戏：菜单 → 开局（确认矿场里不再刷道具）→ 暂停/恢复 → 自动瞄准挖矿 →
逐关过关（时间到达标 / 时间到未达标结束 / 挖空矿场拿奖励 三条路径都走一遍）→ **每关过后进商店**
（买卖扣分、钱不够买不了、预览矿场=正式矿场、道具跨关保留）→ 连玩两关随机关卡 → 校验随机生成器

重开再结算，并校验**音效叠加**（同时 ≥ 2 路、静音立刻停声），最后在**有贴图**和
**没有贴图（矢量兜底）**两种模式下各渲染一遍；任何异常都会让进程非 0 退出。
